# Story 5.10 : Panneau de détails du nœud sélectionné

## Status

Draft

## Story

**En tant que** joueur,
**je veux** un panneau droit qui détaille le nœud sélectionné (comme le panneau
Details d'Unreal) : identité, mod fournisseur, permission, description, et tous ses
littéraux en formulaire,
**afin de** comprendre et paramétrer un nœud sans zoomer dessus — et d'éditer
confortablement les valeurs longues que l'édition inline (5.2b) tronque.

## Acceptance Criteria

1. **Panneau droit repliable (`Tab`)** (UX §2) : sélection simple → titre traduit,
   identifiant technique, catégorie, mod fournisseur, badge de permission (`🔒`
   ADMIN etc.), coût de fuel, pur/impur, description traduite (`descKey`) sur
   plusieurs lignes.
2. **Formulaire des littéraux** : chaque pin d'entrée data avec sa valeur, éditable
   via les mêmes contrôles que la 5.2b (une seule implémentation de contrôles,
   partagée) — champ large, pas tronqué. Pins câblés : « ← connecté à <nœud> »,
   cliquable (recentre sur la source).
3. Sélection multiple → compte des nœuds et actions groupées (supprimer, aligner
   quand la 5.7 existera) ; sélection vide → propriétés du **blueprint** (id, nom,
   description, version, permission plafond — éditables, `BlueprintMeta`).
4. Nœud fantôme → identité brute, mod manquant, littéraux conservés listés en
   lecture seule (préparation FR40).
5. État pur testé (contenu affiché par type de sélection, commit littéral via la
   même voie que 5.2b) ; largeur 120 px, superposition sous 800 px (UX §2).

## Dev Notes

- Tout vient de `NodeDescriptor` + `Blueprint` : aucun accès au `NodeType` (P1).
- Le fournisseur est le namespace de l'identifiant — l'affichage « mod » réel

  dans l'écran, pas dans les panneaux.
