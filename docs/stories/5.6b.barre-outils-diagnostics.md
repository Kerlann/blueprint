# Story 5.6b : Barre d'outils, compilation à la volée et diagnostics

## Status

Ready for Review

## Story

**En tant que** joueur,
**je veux** une barre d'outils (Compiler, Tester, Enregistrer, Script) et une barre
d'état qui me montre erreurs et avertissements en continu, chaque erreur pointant son
nœud,
**afin de** savoir en permanence si mon graphe est valide — principe U3 : « l'erreur
pointe un nœud », jamais de message générique.

## Acceptance Criteria

1. **Barre d'outils 24 px** (UX §2) : identifiant du blueprint + ● dirty (5.9),
   boutons `Compiler`, `Tester`, `Script` (5.11), `Enregistrer`, `×` fermer —
   traduits, avec infobulles.
2. **Validation à la volée** : à chaque mutation, `GraphValidator.validate` est
   relancé **débouncé ≈ 300 ms** (jamais dans la frame de rendu, jamais bloquant) ;
   la barre d'état affiche `⚠ n avertissements ✕ n erreurs`. (AC2 PRD 5.6)
3. Cliquer la barre d'état **déplie la liste** des diagnostics : sévérité, message
   traduit (`Diagnostic` porte code + arguments de traduction), nom du nœud ;
   **cliquer une entrée recentre la caméra sur le nœud fautif et le sélectionne**
   (`Shift+F` recadre déjà sur la sélection). (AC3 PRD 5.6)
4. Le nœud fautif porte un **liseré de la couleur de la sévérité** (erreur `#F7768E`,
   avertissement `#E0AF68`) ; l'infobulle du nœud donne le détail (UX §8).
5. **Compiler** force une validation + compilation immédiate (`Compiler` du core) et
   affiche le résultat ; **Tester** est grisé avec la raison en infobulle tant qu'il
   reste une erreur bloquante, sinon il enregistre + active + déclenche
   l'événement de test (5.9). (UX §8)
6. Débouncé, liste, et association diagnostic→nœud testés headless ; le rendu
   (barres, liserés) reste widget.

## Dev Notes

- `GraphValidator.validate(bp, lookup)` retourne les `Diagnostic` typés — codes déjà
  traduits en/fr (`blueprint.diag.*`, épic 1). Le client N'INVENTE aucun message.
- Le débouncé s'implémente pur avec une horloge injectée (`LongSupplier`) — pas de
  `System.currentTimeMillis` en dur, sinon intestable (leçon des scripts Workflow).
- 500 nœuds : `validate` reste sous la milliseconde (graphes de test épic 1) — le
  débouncé protège surtout de la validation à chaque frappe de littéral.
- La compilation réelle (`Compiler`) peut échouer là où la validation passe : le
  bouton Compiler affiche les deux étages.
