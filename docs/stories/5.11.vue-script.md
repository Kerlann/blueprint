# Story 5.11 : Vue script — le graphe en texte

## Status

Draft

## Story

**En tant que** joueur,
**je veux** basculer sur une vue partagée graphe | BScript avec sélection
synchronisée, copier le script, l'exporter, ou en importer un,
**afin de** lire mon blueprint en texte, le versionner, le partager — U6. Le
générateur et le parseur (épic 4) sont complets et testés : cette story n'est que de
l'interface.

## Acceptance Criteria

1. Le bouton **`Script`** (barre 5.6b) bascule en vue partagée : canevas à gauche,
   panneau BScript à droite (50/50, séparateur glissable) ; re-bascule = plein
   canevas. (UX §9)
2. Le texte est **régénéré débouncé** après chaque mutation (même mécanique que la
   validation 5.6b) ; coloration syntaxique minimale (mots-clés, identifiants,
   littéraux, commentaires) et numéros de ligne.
3. **Sélection synchronisée** : sélectionner un nœud surligne son bloc dans le
   texte et l'y fait défiler ; cliquer un bloc dans le texte sélectionne et
   recentre le nœud. (UX §9 — v1.0 lecture seule, l'édition texte re-parsée est
   explicitement v1.1)
4. **Copier** (tout le script vers le presse-papier), **Exporter** (fichier
   `config/blueprint/exports/<id>.bp`, même chemin que `/blueprint export`),
   **Importer** (remplace le graphe après confirmation U2, une entrée d'annulation).
5. La correspondance nœud↔plage de texte est fournie par le générateur (positions
   par nœud) ou reconstruite de façon testée ; état pur testé headless (bascule,
   correspondance, import = restauration annulable).
