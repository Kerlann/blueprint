# Story 7.7 : Événement command — /bpc

## Status

Ready for Review

## Story

**En tant que** joueur,
**je veux** qu'un blueprint déclare une commande que je tape en jeu,
**afin de** déclencher mes graphes à la demande, avec un argument texte.

## Acceptance Criteria

1. Le nœud `event/command` (le SEUL nœud d'événement avec une entrée) porte le nom
   de la commande en **littéral** ; charge utile : `player`, `name`, `arg`.
2. `/bpc <nom> [texte]` déclenche tous les blueprints ACTIFS déclarant ce nom —
   suggestions = les noms **vivants** ; blueprint désactivé = commande retirée
   (plus suggérée, déclenchement refusé traduit). (AC PRD)
3. L'argument texte traverse la charge utile jusqu'au graphe (testé headless).
4. Déviation consignée : préfixe fixe `/bpc` plutôt que des commandes racines —
   Brigadier ne sait pas retirer proprement un nœud racine ; le préfixe donne la
   dynamique (suggestions vivantes) sans fuite de dispatcher.
