# Stories 4.1 + 4.2 + 4.3 : BScript v1 — génération et parsing fidèles

## Status

Ready for Review

## Story

**En tant que** joueur et mainteneur,
**je veux** que tout graphe se génère en texte lisible et que ce texte se re-parse en graphe identique,
**afin de** versionner, diff-er, partager et éditer mes blueprints comme du code (FR23-FR25).

> Périmètre v1 assumé : sous-ensemble **annoté et total** de la grammaire de
> `bscript-spec.md` — appels nommés, expressions imbriquées de purs, blocs de branches
> uniformes (`type(args) { pin: { … } }`), étiquettes/goto pour les fusions et boucles,
> `@id`/`@pos` partout pour la fidélité. Le sucre (`if` nu, `wait 20t`, opérateurs
> infixes, `$pin` sans préfixe hors événement) = itération 4.2b sur cette base.

## Acceptance Criteria

1. **4.2 — Générateur** : `ScriptGenerator.generate(bp, lookup)` produit un texte **déterministe** (même graphe → mêmes octets, testé par double génération) : en-tête + meta, variables (types structurels `list<int>` inclus), notes, un bloc `on <event>(sorties…)` par nœud d'événement (triés par UUID), chaînes exec linéaires, purs **inlinés** en expressions (partagés dédupliqués par `@id`), branches en blocs par pin, fusions/boucles en `label:`/`goto` (repli spec §6), littéraux typés échappés.
2. **4.3 — Parseur** : `ScriptParser.parse(texte, registries)` reconstruit le graphe — erreur de syntaxe → résultat d'échec avec **ligne + message**, jamais d'exception ; nœud inconnu → **fantôme** (spec §7) ; `@id` absent → UUID généré ; `@pos` absent → mise en page automatique déterministe.
3. **Round-trip pivot** : démo réelle (7 nœuds, 2 événements, branche, purs) → texte → parse → `contentEquals` ; et `generate(parse(generate(g))) == generate(g)`.
4. Cas couverts en test : variables 4 portées + défauts + `list<int>`, boucle exec (goto), pur partagé entre deux consommateurs (un seul nœud au retour), notes, fantôme minimal, erreurs (ligne correcte, pas de crash).
5. **Câblage fichiers** : `BlueprintFiles.export` écrit désormais du **BScript texte** dans `.bp` ; `importFile` détecte le format (magie gzip → NBT hérité, sinon texte) — les `.bp` NBT existants restent importables.
