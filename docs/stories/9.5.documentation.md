# Story 9.5 : Documentation utilisateur

## Status

Done

## Story

**En tant que** joueur qui découvre le mod,
**je veux** un guide qui me fait réussir mon premier blueprint,
**afin de** ne pas devoir lire une spécification d'architecture pour poser deux nœuds.

## Acceptance Criteria

1. **Guide de prise en main** destiné au joueur : ouvrir l'éditeur, un premier
   blueprint en cinq gestes, les raccourcis, les variables, le dépannage.
2. **Référence des nœuds générée depuis le registre** — jamais écrite à la main.
3. Le guide d'intégration des mods tiers existe déjà (`extension-api.md`, mis à jour
   d'après l'implémentation en 8.1 et 8.2) ; les deux nouveaux documents sont liés
   depuis l'index.

## Dev Agent Record

- claude-fable-5 — `NodeReferenceTest` vert, build complet vert.
- **La référence est vérifiée, pas seulement générée** : le test compare le fichier
  commité à ce que produit le registre courant et **échoue s'ils divergent**. Ajouter un
  nœud sans régénérer casse la construction — c'est la seule façon qu'une documentation
  reste vraie. Régénération :
  `./gradlew :core:test --tests "*NodeReferenceTest" -Dblueprint.regenDocs=true`
  (la propriété est explicitement transmise à la JVM des tests : sans ça, `-D` ne parle
  qu'au démon Gradle — piège rencontré).
- Sortie **déterministe** : catégories triées, nœuds triés par identifiant. Un diff de
  la doc doit montrer ce qui a changé dans le registre, rien d'autre.
- Les titres viennent des **clés de traduction** (`en_us`) : la doc et le jeu disent la
  même chose, et le test d'i18n (9.4) garantit que ces clés existent.
- 78 nœuds, 12 catégories dans la version générée.
- Le guide joueur assume ce qui a été appris en développant : il explique le message
  « lecture seule », les nœuds fantômes (« vos graphes sont intacts, réinstallez le
  mod »), et le fait qu'en solo l'édition marche **même sans tricheurs** (corrigé en 9.2).
- **VERIFY-9.5** (session finale) : suivre le guide §3 à la lettre, sans rien savoir
  d'autre, et obtenir le message de bienvenue.
