# Story 7.1b : Flux structuré — sequence, for, while, do_once, wait_until, switch

## Status

Ready for Review

## Story

**En tant que** joueur,
**je veux** des boucles, des séquences et des aiguillages,
**afin d'** écrire de la vraie logique — le manque le plus visible de la
bibliothèque depuis la 7.1a.

## Acceptance Criteria

1. **Frames VM minimales** : pile d'adresses de retour dans `ExecutionState`
   (persistée — une suspension au milieu d'une boucle survit au redémarrage),
   instruction `CallSub`, et « cible pendante = dépiler » ; `Return` reste terminal
   pour toute l'exécution.
2. Le reste est **abaissé par le compilateur** sans nouvel opcode métier :
   `sequence` (CallSub par branche), `while`/`for` (JmpIf + arêtes arrière + Calls
   synthétisés vers `math/add`/`logic/less_eq` — le compilateur fabrique son
   arithmétique avec la bibliothèque standard), `wait_until` (Yield 1 + reboucle),
   `do_once` (drapeau caché en variable GRAPH, persiste avec le VarStore),
   `flow/return` (Return dur). `switch` est un nœud à action classique (routage).
3. Les conditions de boucle se **ré-évaluent à chaque itération** (l'arête arrière
   revient AVANT la préparation des entrées — contrat déjà posé par la 3.x).
4. `for` expose `index` en sortie data consommable dans le corps ; bornes
   inclusives ; boucle infinie = bornée par le fuel (NFR4), jamais un gel.
5. Six tests bout-en-bout headless : ordre de séquence, somme for 1..3 (=6) +
   completed, while jusqu'à 3, do_once persistant entre exécutions, wait_until
   suspend/reprend, switch. Restes consignés : `gate` (entrées exec multiples =
   points d'entrée par pin, non supporté par le linearizer), `for_each` (listes v1.1).

## Dev Notes / Dev Agent Record

- claude-fable-5 — tests verts au premier passage réel (une reprise : API NBT
  `getIntArray(...).orElse`).
- Décision d'architecture : frames MINIMALES (une pile d'entiers) plutôt qu'un
  système de frames complet — tout le contrôle de flux se compile vers 3 primitives
  (CallSub, JmpIf, Yield) + des Calls purs synthétisés. Les instructions
  arithmétiques n'existent pas dans l'IR : le compilateur appelle la bibliothèque.
- Correction de contrat au passage : la fin de fil d'un `var/set` émettait `Return`
  (terminal global) — devenu `Jmp(-1)` (fin de sous-chaîne) pour que les corps de
  boucle rendent la main.
