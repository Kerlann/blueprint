# Story 5.7 : Confort d'édition — commentaires, alignement, minimap, thème

## Status

Ready for Review

## Story

**En tant que** joueur,
**je veux** des boîtes de commentaire, l'alignement automatique, une minimap et un
thème personnalisable,
**afin d'** organiser des graphes qui grossissent — le dernier étage du confort
Unreal.

## Acceptance Criteria

1. **Commentaires** : `C` entoure la sélection d'une boîte de commentaire
   (`CommentBox` du modèle, ops existantes à vérifier) — titre éditable, couleur,
   redimensionnable ; **déplacer la boîte déplace les nœuds qu'elle contient**.
   (AC1 PRD 5.7)
2. **Alignement et distribution** : `Q` aligne la sélection (gauche/haut selon la
   dominante), menu contextuel : aligner gauche/droite/haut/bas, distribuer
   horizontal/vertical — chaque action = une entrée d'annulation. (AC2 PRD 5.7)
3. **Auto-layout** (`Ctrl+Shift+A`) : mise en page automatique par couches suivant
   le flux exec (gauche→droite), données au-dessus — `core/script/AutoLayout.java`
   (prévu par l'arborescence, à écrire ; servira aussi à l'import BScript sans
   positions). (AC2 PRD 5.7)
4. **Minimap** (coin bas-droit, UX §2) : vue d'ensemble cliquable (téléporte la
   caméra), rectangle de vue courant, repliable ; `Ctrl+F` « aller au nœud » :
   mini-palette de recherche qui recentre. (AC3 PRD 5.7)
5. **Thème JSON** : `assets/blueprint/theme/default.json` (jetons UX §12) chargé au
   démarrage, rechargeable en dev (F3+T) ; TOUTES les couleurs en dur de l'éditeur
   (canevas, nœuds, pins par défaut, liens, palette, panneaux) migrent vers le
   thème ; thème « fort contraste » fourni. (AC4 PRD 5.7, NFR11)
6. Logique pure testée : contenance des commentaires, alignement/distribution,
   auto-layout déterministe (même graphe → mêmes positions), parse du thème avec
   défauts sur clés manquantes.
