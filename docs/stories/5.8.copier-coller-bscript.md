# Story 5.8 : Copier / couper / coller / dupliquer via BScript

## Status

Draft

## Story

**En tant que** joueur,
**je veux** `Ctrl+C/X/V` et `Ctrl+D` sur ma sélection, avec un presse-papier qui est
du **texte BScript**,
**afin de** réutiliser des morceaux de graphe — et de les partager : coller dans
Discord un bout de blueprint lisible, c'est le principe U6 (« le texte est une porte
de sortie »). L'épic 4 (générateur + parseur) est complet : cette story est le pont
éditeur↔BScript.

## Acceptance Criteria

1. **`Ctrl+C`** sérialise la sélection en BScript dans le presse-papier **système**
   (partageable hors du jeu) : sous-graphe = nœuds sélectionnés + liens internes +
   littéraux + variables référencées (déclarées en tête). `Ctrl+X` = copie puis
   suppression (une entrée d'annulation).
2. **`Ctrl+V`** parse le presse-papier (`ScriptParser`) : succès → insertion au
   curseur avec **UUID neufs**, positions décalées en bloc (le coin haut-gauche du
   fragment sous le curseur, accroché), la nouvelle sélection = les nœuds collés ;
   échec de parse → message d'état, rien n'est inséré. Coller deux fois = deux
   copies indépendantes.
3. **`Ctrl+D`** duplique la sélection décalée de +16/+16 sans passer par le
   presse-papier système.
4. Variables référencées absentes du blueprint cible : créées si déclarées dans le
   fragment, sinon le nœud Get/Set colle en **fautif** (liseré 5.6b) — jamais de
   refus silencieux du collage.
5. Round-trip testé headless : sélection → copie → collage = graphes équivalents à
   translation et UUID près ; collage d'un texte invalide = état inchangé ;
   duplication = une entrée d'annulation.

## Tasks / Subtasks

- [ ] `core/script` : extraction de sous-graphe (`SubgraphExtractor` ou surcharge de
      `ScriptGenerator.generate` sur un sous-ensemble de nœuds) — décision : vit
      dans `core` (réutilisé par 9.x) (AC1)
- [ ] Collage : `ScriptParser.parse` → blueprint fragment → réémission en
      `AddNode`/`SetLiteral`/`AddLink` (UUID neufs, translation, accroche) via
      `CanvasController` — une entrée d'annulation (AC2, AC3)
- [ ] Presse-papier système : `Minecraft.keyboardHandler` (getClipboard/
      setClipboard — vérifier les noms au javap) ; `Ctrl+D` court-circuite (AC1, AC3)
- [ ] Gestion variables du fragment (déclaration en tête de BScript) (AC4)
- [ ] Tests headless sur le cycle complet (le presse-papier système est mocké par
      un `Supplier/Consumer<String>` injecté) (AC5)
- [ ] Clés de langue (échec de parse) en/fr ; `./gradlew build` vert
